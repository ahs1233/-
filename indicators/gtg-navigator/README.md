# GTG Navigator — مؤشر ملاحة سعرية لـ TradingView (Pine Script v6)

يجمع المؤشر **المسار** (الإطار الأعلى + الهيكل الحالي)، و**الاتجاه الآن**، و**السرعة**، و**الوقود** (الدفع/المشاركة)، مع **خريطة من أربع مناطق** (R1/R2 فوق السعر و S1/S2 تحته) ولوحة HUD عربية مختصرة.

> القيم 0..100 رتب قياس نسبية وليست احتمالية ربح. المناطق عوائق ومناطق اهتمام، وليست أهدافًا مضمونة. التنبيهات تغيّر حالة فقط، وليست توصيات تداول.

| الملف | الحالة |
|---|---|
| `gtg_navigator_v0.4.7.pine` | **النسخة الحالية.** محرك المناطق أُعيدت كتابته وفق معمارية v0.4.7-B المجمّدة. **التنفيذ مكتمل؛ التحقق الخارجي في TradingView معلّق.** |
| `gtg_navigator_v0.4.6.pine` | المرجع القديم (legacy engine)، محفوظ كما هو للمقارنة المباشرة. |
| `reference/` | نموذج مرجعي بـ JavaScript لخوارزميات المحرك + اختبارات T0–T7. |

## التركيب على TradingView

1. افتح **Pine Editor** في TradingView.
2. الصق محتوى `gtg_navigator_v0.4.7.pine` كاملًا.
3. اضغط **Add to chart**.
4. للتنبيهات: **Create Alert** ← `GTG Nav v0.4.7` ← أحد الشروط العشرة.

الفريمات المدعومة: من الثواني حتى الشهري (1M). عند فريم لا يحقق `chart < A1 < A2` يتوقف المؤشر برسالة خطأ.

## v0.4.7 — ما تغيّر

الأقسام 1–7 (الحساسات، السرعة، الاتجاه، المسار، الوقود) منقولة من v0.4.6 دون تغيير منطقي. الأقسام 8–12 (محرك المناطق) أُعيدت كتابتها بالكامل، والأقسام 13–17 عُدّلت وفق عقد المستهلكين.

### محرك المناطق (الأقسام 8–12)

| المرحلة | ما تفعله |
|---|---|
| **الأساس (8–9)** | ثوابت أعداد صحيحة محدودة، ملفات فريم (`pivotLen`، أعمار، نافذة Flip، A1/A2)، ATR بذاكرة محدودة `SMA(TR, 20)` على الرسم وA1 وA2، وجلب الـanchors كقيم scalar من شموع HTF مغلقة فقط. |
| **الذاكرة البنيوية (10)** | مستويات دائمة: pool محلي (سعة 48، إخلاء الأقدم ولادة) لـSWING وDOZ، وpool منفصل لكل من A1 وA2 يتبع مفاتيح الـfeed الحالية (آخر 3 قمم + 3 قيعان؛ الميت يبقى tombstone طالما مفتاحه في الـfeed). لكل مستوى state machine: `ACTIVE → BREAKING → BROKEN → FLIP_CONFIRMED → DEAD` مع العودة `BREAKING → ACTIVE`، وحلقات اختبار تفصل **mitigation** (استهلاك) عن **evidence** (رفض). |
| **بناء المناطق (11)** | فرز حسب `lo` ← مكونات متصلة (`gap ≤ mergeGap`) ← **Component Packing** حتمي ← مجموعات أحداث MTF (السوينغ والـpivot الأعلى للحدث نفسه = مكافأة MTF واحدة) ← `gateQ` (بوابة) و`displayQ` (عرض؛ MA والمستويات النفسية هنا فقط). |
| **الاختيار (12)** | أفق عالمي تدريجي `R*` يوسّعه الـanchor المؤهل، و`R_eff` للـhysteresis، ثم الأقرب أولًا لكل المصادر، ومنطقة محتوية تأخذ R1 أو S1 حسب جهة الدخول، و`Q_enter/Q_stay` عبر `entryKeys` حية. |
| **الخانات** | أربع `SlotState` بقيم scalar + ثماني مصفوفات int مملوكة لكل خانة (`entryKeys`/`lastKeys`) تُحدَّث بـclear + push فقط، بلا حد أقصى لعدد المفاتيح؛ لا مرجع Zone دائم، ولا نسخ سطحي، ولا `prevZones`. |

**قواعد ثابتة:** هندسة المناطق والخانات تتغير عند إغلاق الشمعة فقط؛ لا مناطق خام تُرسم؛ لا `[1]` على UDT أو مصفوفة؛ لا `varip`؛ لا ATR بذاكرة غير محدودة داخل المحرك؛ `memberKey = birthTime × 32 + disc` مع `0 ≤ disc ≤ 17 < 32`.

**الحتمية:** كل حالة داخل المحرك محدودة العمر بـ`T_max` شمعة رسم، والمحرك يعمل على آخر `W = 2·T_max + L_entry + N_leg + pivotLen + 10` شمعة. لذلك نفس آخر W شمعة مغلقة ⇒ نفس الخريطة.

### DEBUG وinvariants

في وضع اللوحة `DEBUG` يظهر: عدد مخالفات الـinvariants وآخر رمز، `suppressed` (للشمعة/الإجمالي، أعلى جودة، أقرب مسافة)، أكبر عدد مفاتيح في خانة، تكرار المفاتيح، و`R_eff`.
مع `strictDebug = true` أي مخالفة حرجة (I1–I6، I8–I12، تكرار المفتاح، عمر سالب، na في الفرز، anchor pool > 6) توقف المؤشر بـ`runtime.error`.

### ما تغيّر للمستهلك (13–17)

- `dest1` = المنطقة المحتوية إن وُجدت، وإلا اختيار الاتجاه كما في 4.6. المسافات بـ`ATR_eng`.
- أحداث الكسر والرفض والقبول والـFlip مصدرها الوحيد state machine المستويات، ولا يوجد كاشف موازٍ.
- حالة الطريق: فرعان جديدان للكسر المقبول، وحُذفت فروع الـOrder Block القديمة، وتُلحق وسوم «Flip محتمل / Flip مؤكد / قيد الكسر».
- تنبيهان جديدان: **Break Accepted** و**Flip Confirmed**. تنبيه الكسر أصبح «(قيد التأكيد)».
- عتبتا القوة (72/48) أصبحتا مدخلين `strongQ` و`mediumQ`.

## النموذج المرجعي والاختبارات

```bash
node --test indicators/gtg-navigator/reference/engine.test.mjs
```

| الاختبار | ما يثبته |
|---|---|
| T0 | `memberKey` حقن (injective) ولا تصادم؛ المميّز < 32 |
| T1 | 150 تبديلًا لترتيب المرشحين ⇒ نفس الخريطة |
| T2 | سلسلة متصلة أعرض من `maxWidth` ⇒ packing واحد حتمي، والمهمَل لا يساهم |
| T3 | سوينغ M1 + pivot M15 للحدث نفسه ⇒ مكافأة MTF واحدة، لا مكافأتين |
| T4 | محلي عند 7 ATR وA2 عند 10 ATR ⇒ R1 = المحلي ثم R2 = A2 |
| T5 | امتياز `Q_stay` يسقط عند موت أعضاء الدخول |
| T6 | اختراق عميق + رفض ضعيف يستهلك أكثر من اختراق عميق + رفض قوي |
| T7 | إعادة التحميل: نفس آخر W شمعة ⇒ نفس الخريطة (محلي + DOZ + A1/A2) |
| T8 | دورة حياة الـanchor تتبع الـfeed: لا طرد لـanchor حية، والـtombstone فقط أثناء وجود مفتاحها في الـfeed |
| T9 | منطقة بأكثر من 6 أعضاء: الامتياز ومفاتيح الأحداث لا تُقتطع |

الاختبارات تثبت المنطق لا تشغيل Pine: ملف Pine ترجمة يدوية لنفس الخطوات. التطابق بين الصيغ في Pine والنموذج المرجعي روجع للنقاط: memberKey، معادلة mitigation، مضاعفات الحالة، مكافأة MTF، ترتيب الـpacking والإهمال، gateQ، R*، R_eff، Q_enter/Q_stay، المنطقة المحتوية، والاختيار المكاني.

## بوابات التحقق الخارجية (معلّقة)

- **G1** الترجمة في Pine Editor.
- **G2a–G2g** الأداء عبر Pine Profiler: الزمن الكلي، أطول حلقة < 500ms، أسوأ حالة XAUUSD/BTCUSDT M1، الذاكرة والكائنات، زمن الترجمة، طلبات `request.*()` (3 طلبات، 45 عنصر tuple)، لا na داخل أي فرز.
- **G3** صفر مخالفات مع `strictDebug`.
- **G4** اختبار الترتيب في النموذج المرجعي (منجز: T1، T7).
- **G5** معايرة القيم الابتدائية (`Q_enter/Q_stay`، `k_L/k_1/k_2`، `mergeGap`، `maxWidthK`، `α`، `R_rej`، `b`، `d`، `e`، `ε`، 72/48).

## قيود معروفة

- لا Footprint ولا DOM ولا Level 2 ولا Volume Profile مدفوع. «الوقود» تقريب للمشاركة، وعلى الذهب الفوري يعتمد على نشاط التيك.
- المستويات النفسية وMA200/MA1000 تلاقٍ بصري فقط، ولا تدخل بوابة التأهيل.
- DOZ (Displacement Origin Zone) بديل سعري للاندفاع وليس Order Block مؤسسي.
