## 2. محرك التقسيم الهيكلي — التصميم

### 2.1 كشف نقاط التذبذب (ATR-threshold Zigzag)

بدلاً من `pivotLen` الثابت في zone-engine، نستخدم عتبة ATR ديناميكية:
- نقطة تذبذب تُثبّت عندما ينعكس السعر بمقدار `threshold × ATR(14)` من الحد الأقصى
- كل نقطة تحمل: `bar` (النقطة الفعلية)، `confirmBar` (أول شمعة حيث تحققت العتبة)

**عتبات لكل إطار زمني:**

| الإطار | العتبة | المنطق |
|--------|--------|--------|
| M5 | 1.0 ATR | حساسية عالية للسكالبنغ |
| H1 | 1.2 ATR | تصفية وسيطة |
| H4 | 1.5 ATR | موجات سوينغ واضحة |
| D | 2.0 ATR | هيكل ماكرو فقط |

### 2.2 تصنيف نقاط التذبذب

كل نقطة تُصنّف نسبة لسابقتها من نفس الجانب:
- **HH** (Higher High) / **LH** (Lower High) / **EH** (Equal High)
- **HL** (Higher Low) / **LL** (Lower Low) / **EL** (Equal Low)

### 2.3 كشف الأحداث الهيكلية

- **BOS** (Break of Structure): استمرار الاتجاه — HH بعد HH أو LL بعد LL
- **CHoCH** (Change of Character): أول كسر ضد الاتجاه — LH بعد HH أو HL بعد LL

### 2.4 تصنيف السيقان (Leg Types)

كل ساق بين نقطتي تذبذب متتاليتين تُصنّف:

| النوع | الشرط |
|-------|-------|
| `impulse` | كفاءة المسار ≥ 0.55 ومسافة ≥ 1.5 ATR، مع الاتجاه |
| `reversal_impulse` | نفس الشرط، ضد الاتجاه |
| `shallow_pullback` | تراجع ≤ 23.6% |
| `pullback` | تراجع 23.6–61.8% |
| `deep_pullback` | تراجع 61.8–100% |
| `range` | مسافة < 0.5 ATR |
| `choppy` | كفاءة مسار < 0.35 |
| `continuation` | مع الاتجاه (غير مصنّف أعلاه) |
| `correction` | ضد الاتجاه (غير مصنّف أعلاه) |

### 2.5 بيانات وصفية لكل ساق

`distanceAtr` · `duration` · `durationMs` · `retracement%` · `pathEfficiency` · `velocity` · `acceleration` · `MFE` · `MAE` · `atrStart` · `atrEnd` · `atrChange%`

### 2.6 كشف الانضغاط/التوسع

مقارنة متوسط ATR لآخر 20 شمعة مقابل الـ 20 السابقة:
- `compression`: النسبة < 0.85
- `expansion`: النسبة > 1.15
- `neutral`: بين الحدين

## 7. مواصفات السببية (Causal Spec)

### 7.1 التقسيم البعدي (Ex-post)

نقاط التذبذب تستخدم شموعاً مستقبلية للتأكيد (وسم الحقيقة الأساسية). نقطة عليا عند شمعة i تُوضع عند الحد الأقصى الفعلي، حتى لو لم تكن معروفة حتى شمعة التأكيد j. **التقسيم البعدي مسموح فقط لبناء أطلس الهيكل ووسوم التدريب.**

### 7.2 الوضع الآني (Online)

الوضع الآني يستخدم `confirmBar`: التذبذب لا يكون مرئياً للمحرك حتى تتحقق عتبة الانعكاس. كل التحليل اللاحق (نوع الساق، حالة الاتجاه، BOS/CHoCH) مشروط بـ `confirmBar`. **لا يُسمح لأي شمعة قبل `confirmBar` باستخدام نقطة التذبذب هذه.**

### 7.3 تأخير التأكيد

التأخير متأصل في العتبة: عتبة 1.0 ATR على M5 تعني أن التذبذب يُعرف بعد ~1 ATR من الحد الأقصى. عتبات أصغر تكشف أسرع لكن تنتج ضوضاء أكثر؛ عتبات أكبر أكثر صلابة لكن تُدخل تأخيراً.
